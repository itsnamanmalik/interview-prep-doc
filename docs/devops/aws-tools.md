# AWS Tools

- **Amazon EC2 (Elastic Compute Cloud)**: Provides scalable virtual servers for running applications.

- **Amazon S3 (Simple Storage Service)**: Object storage service for storing and retrieving any amount of data.

- **Amazon RDS (Relational Database Service)**: Managed relational database service for databases like MySQL, PostgreSQL, and Oracle.

- **AWS Lambda**: Serverless computing service that runs code in response to events and automatically manages the compute resources.

- **Amazon CloudWatch**: Monitoring and observability service for AWS resources and applications.

- **AWS IAM (Identity and Access Management)**: Manages access to AWS services and resources securely.

- **AWS SQS (Simple Queue Service)**: Fully managed message queuing service for decoupling and scaling microservices.

- **AWS SNS (Simple Notification Service)**: Managed service for sending notifications and messages.

- **Amazon ECR (Elastic Container Registry)**: Managed Docker container registry that makes it easy to store, manage, and deploy Docker container images.

- **AWS Elastic Beanstalk**: Platform as a Service (PaaS) for deploying and managing applications.

- **AWS Secrets Manager**: Protects access to your applications, services, and IT resources without the upfront investment and maintenance of operating your own infrastructure.

- **Amazon EKS (Elastic Kubernetes Service)** is a fully managed Kubernetes service that simplifies the process of running Kubernetes on AWS. It allows you to deploy, manage, and scale containerized applications using Kubernetes, without having to manage the underlying Kubernetes infrastructure yourself.
